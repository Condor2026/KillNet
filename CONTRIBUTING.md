# Guía para Colaboradores

## 📋 Cómo Contribuir

### 1. Reportar Errores o Faltas
- Abre un **Issue** en GitHub
- Describe el error con detalle
- Proporciona fuentes verificables
- Usa la etiqueta `bug`

### 2. Sugerir Mejoras
- Abre un **Issue** con la etiqueta `enhancement`
- Explica tu propuesta
- Aporta contexto o ejemplos

### 3. Aportar Nuevos Datos OSINT
- Asegúrate de que sea de **fuentes abiertas y verificables**
- Proporciona enlaces o capturas
- No compartas información clasificada
- Usa la etiqueta `ioc` o `threat`

### 4. Pull Requests
1. Haz un **fork** del repositorio
2. Crea una **rama**: `git checkout -b feature/tu-mejora`
3. Realiza tus cambios
4. Asegura que el formato Markdown sea correcto
5. Envía un **Pull Request**

---

## 📝 Estilo y Formato

### Markdown
- Usa títulos con `#` y `##`
- Listas con `-` o `1.`
- Código con ` ``` `
- Tablas con formato estándar

### Estilo de Escritura
- Lenguaje claro y directo
- Evita tecnicismos innecesarios
- Mantén un tono profesional
- Cita siempre las fuentes

---

## 🔒 Reglas de Seguridad

### NO Publicar
- Información personal no verificada
- Datos de víctimas no anonimizados
- Credenciales activas
- Información clasificada

### SÍ Publicar
- Datos de fuentes públicas
- IOCs (Indicadores de Compromiso)
- Análisis de TTPs
- Recomendaciones de seguridad

---

## 📚 Fuentes Permitidas

### Válidas
- Canales de Telegram públicos
- Foros de ciberseguridad
- Informes de agencias (NCSC, CISA, Europol)
- Artículos de prensa verificados

### No Válidas
- Información clasificada
- Datos de fuentes anónimas no verificadas
- Material de hacking activo

---

## 👥 Código de Conducta

1. **Respeto:** Trata a todos con respeto
2. **Transparencia:** Sé honesto sobre tus fuentes
3. **Legalidad:** No promuevas actividades ilegales
4. **Ética:** La información es para defensa, no para ataque

---

## 📊 Etiquetas de Issues

| Etiqueta | Uso |
|:---|:---|
| `bug` | Error en la información |
| `enhancement` | Sugerencia de mejora |
| `documentation` | Problemas con la documentación |
| `ioc` | Nuevos indicadores de compromiso |
| `threat` | Nueva amenaza identificada |
